1.1 RATE LIMITING EN LOGIN (nuevo)
- Dependencia agregada: express-rate-limit@8.6.2 (justificacion: solucion

1.2 CORS
- backend/src/app.js: reemplazado cors() abierto por lista explicita:
  * Origenes de desarrollo: http://localhost:5173, http://127.0.0.1:5173,
    http://localhost:5174, http://127.0.0.1:5174.
  * Origenes adicionales via variable de entorno CORS_ORIGINS
    (lista separada por comas), para el futuro dominio de produccion.
    Ejemplo (conceptual, sin dominio real): CORS_ORIGINS=http://localhost:5173
  * Requests SIN cabecera Origin (aplicaciones nativas Tauri/Android futuras)
    se permiten: no se rompe el acceso de apps instaladas.
  * Origenes fuera de la lista: no se emiten cabeceras CORS (el navegador
    rechaza la respuesta). No se usa origin: "*".
